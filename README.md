Entry for make.fun's "One Word, One Username, One Reward" bounty: the program writes the entrant's own make.fun username — `dansam97`, one word and nothing else — to `entry.txt`, exactly as the contest asks. The handle is validated before writing (exactly one word, 1–30 characters, clean UTF-8) and the file is read back to prove the bytes on disk match.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
